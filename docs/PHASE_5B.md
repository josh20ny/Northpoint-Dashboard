# Phase 5B · Dashboard feedback and Planning Center reporting

**Ready for the coding agent.** Phase 5 closed for development on November 18, 2026. Complete this phase before starting Phase 6. A staff member should be able to open the dashboard, see how last Sunday compared with recent weeks and last year, and follow a number into the ministry that owns it.

The requirements below come from Josh’s 19:38 post–Phase 5 walkthrough and his written source clarification. Timestamps refer to the recording. The [audit](PHASE_5B_AUDIT.md) identifies where the current code differs. The [agent prompt](AGENT_TASK_PROMPTS.md#phase-5b) is ready to use.

## Source selection

Make this decision on the server for **each metric, ministry, population, unit, service scope and period**. Use the existing PCO ingestion, normalized records and publication path. Opening a card or a graph should read a permission-scoped aggregate from the dashboard API.

| What the church recorded | Value the dashboard should use |
| --- | --- |
| PCO covers the requested measure and period | Use the PCO observation or calculate the aggregate from PCO records. An observed zero is a value. An overlapping spreadsheet value is useful for QA, even when it differs. |
| PCO covers it, but a sync, mapping, identity or publication is incomplete | Keep an available PCO subtotal marked **Partial**, or show unavailable with a short reason. Retain the actual as-of time on stale data. Investigate the pipeline instead of allowing an apparently complete workbook cell to mask the problem. |
| The church did not record the measure in PCO, or the period predates actual PCO coverage for that measure | Use a mapped, accepted historical value only if its meaning, scope and date match. Record the reason for the gap, source batch, cell and cutoff. Coverage is per metric and period. There is no single transition year for the church. |
| Adult auditorium attendance | This is the explicit exception. The church counts people seated at each service manually. Use the accepted workbook for historical headcounts and prior-year totals, and native entry for new counts and corrections. Preserve the approved exclusions and corrected revisions. |
| The two sources look alike but count different things, or neither has a usable value | Keep a gap in the requested series. A legacy headcount, membership record, giving person or scheduled volunteer has its own meaning. An older measure may be available as clearly named history when useful. |

Keep raw PCO facts, imported cells, mapping versions and previous publications addressable. An accepted batch needs no per-week reapproval. Compare the two sources on like-for-like observations and record both values, difference, period, as-of dates and reason in authorized reconciliation. A difference may reflect a real later correction or a different population. Do not tune a PCO total to match the worksheet.

Staff should see the measure’s name, calendar period and any material caveat. Remove routine workbook labels, “WB” suffixes, “All services” on group measures, raw flags and source inventories from their normal screens. Keep the lineage and technical diagnostics available to the appropriate reviewer.

**Calculation choices for implementation.** Preserve the implemented adult averaging convention. The trailing window includes its anchor Sunday and uses complete values in the chosen number of calendar weeks, including a measured zero. Apply that convention to comparable weekly KPIs. An eight-week chart point uses that same rule for the eight weeks ending at the point, including prior-year lookback for January when available. Expose the actual denominator. Restrict prior-year comparisons to matching numbered Sundays, definitions, units and scopes. An observed-as-of roster requires real comparable observations for its average or YoY. For Giving, existing policy supplies the General Giving dollar definition and explicit joint-giver grouping. Treat the weekly giving-unit count as participation across qualifying church gifts, counting a unit once regardless of gifts or designations. Keep its fund scope explicit in the definition. A coach mapping or historical role that the source cannot establish stays unavailable.
