# Ministry Scorecard Templates

## Legacy-preservation plan
Current SPD measures include Welcome, Music, Vision, Message, Production, and Walk Away (verify exact categories and original weighting). Kids sheets include numerical scores; Transit/InsideOut have Engage, Involve, Challenge, Overall, including labels such as Double/Triple/Homerun. Preserve original responses and formulas during import, then request owner validation of mappings.

## New authoring model
Admin can define per ministry template: sections, questions, input source (staff/volunteer form), response type (1–4, named ordinal, text, boolean), labels, weights, exclusions/missingness policy and effective date. Published template versions immutable.

## Survey integration
Some scores are averages of service attendee/volunteer ratings from forms, not a single staff rating. Ingest raw survey responses where permitted; if only aggregate data exists, store aggregate + response count + origin and label clearly. Never reverse engineer individual responses from averages.

## Reporting
Per-occurrence score, question distributions/counts (if available), trend, YoY and correlation with attendance annotated as noncausal; scorecards linked to PCO service plans.
