# Operations Playbook (initial)

Daily operator view: integrations freshness, failed jobs, missing Sunday values, pending imports, anomaly alerts, report queue and database health. Every provider connection has owner, reconnect process, incremental cursor and backfill action. Failed weekly reports must remain retryable without duplicates. Manual edits and corrected historical observations preserve version/audit history. Quarterly: restore drill, permission review, token rotation audit, data retention review, forecast calibration and API scope verification.

Phase 5B keeps invitations, Check-In resolution and audit on the Admin landing page. Technical ministry mappings, historical gap fills and publication are backend operator tasks. Use existing scoped operations with replay and validity checks. Imports remains available for occasional legacy files. Keep routine PCO sync controls under Integrations and distinguish the last successful provider sync from a health-page refresh.
