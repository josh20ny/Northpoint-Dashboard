# Phase 5B · Codebase audit

**The first implementation change belongs in source selection.** A rollback-only test of the current staff read reproduced the workbook replacing a partial Planning Center publication. Hiding the word “workbook” in React would leave that behavior intact. Two more requested Home values need server calculations. One counts the giving units that gave during the week. The other counts distinct people active in groups.

Reviewed the [Phase 5 closeout commit](https://github.com/josh20ny/Northpoint-Dashboard/tree/34510f2e9f0b42050b25a39736ea8fc1372dfc76), the full 19:38 walkthrough, the 70 existing Markdown files and the relevant application, query, schema, ingestion and test paths. Findings below concern repository behavior. Test data was synthetic. Development publication dates cited below come from the existing closeout records. This review did not query church accounts or validate live totals.
